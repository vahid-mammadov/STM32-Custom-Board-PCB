# STM32 Sensor Interface & Development Board

## Overview

A custom development and sensor interface board designed around the **STM32F103C8T6** microcontroller for embedded systems applications.

## Features

STM32F103C8T6 microcontroller
Sensor interface circuits
Development and programming interfaces
Power supply and regulation
Custom PCB design
